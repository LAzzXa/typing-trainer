# ⌨️ SpeedType Trainer

> A modern browser-based typing trainer built to improve speed, accuracy, and keyboard skills.

🌐 **[Live Demo](https://LAzzXa.github.io/typing-trainer/)**

---

## 🚀 Features

### 🏁 Online Races

Race your friends in real time.

* Create a race room
* Share the 5-letter room code
* Friends join without creating an account
* Everyone types the same text
* Live race progress
* Free to use

### 📚 Progressive Lessons

Build your typing skills step by step with 3 lessons:

1. **Common Words** — build basic speed
2. **Medium Words** — increase difficulty
3. **Full Sentences** — practice realistic typing

Each lesson tracks your personal best WPM.

### 🎯 Difficulty Levels

Choose your challenge:

* 🟢 Easy
* 🟡 Medium
* 🔴 Hard

Available in **Words** and **Time** modes.

### 🏆 Top Scores

Your best results are saved directly on your device.

* Top 5 scores
* No account required
* Local storage

### 🌙 Light & Dark Mode

Switch between light and dark themes.

Your preference is automatically saved.

### ⌨️ Finger Hint Keyboard

Improve your touch-typing technique with an interactive keyboard.

* Shows the next key to press
* Highlights the recommended finger
* F/J home-row markers
* Visual typing guidance

## ⚡ Run Locally

Clone the repository:

```bash

```

Open the project folder:

```bash
cd typing-trainer
```

Then open `index.html` in your browser.

No installation or build process is required.
